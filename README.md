# Бот для планирования вечеринки

Telegram бот на JavaScript для планирования вечеринки. Проект хранит данные в `data.json` и работает через команды.

## Установка

1. Установите Node.js 22+.
2. В папке проекта выполните:

```bash
npm install
```

3. Создайте файл `.env` в корне проекта с токеном бота:

```bash
TOKEN=ваш_токен
```

4. Запустите:

```bash
npm start
```

## Команды

- `/start` - запустить бота
- `/help` - показать список команд
- `/guest_add имя email` - добавить гостя
- `/guest_remove имя` - удалить гостя
- `/guest_list` - показать список гостей
- `/invite` - отправить приглашения
- `/status имя yes|no|read|прочитано|подтверждено|отклонено` - обновить статус гостя
- `/pref_add музыка1,музыка2 еда1,еда2 тема` - добавить предпочтения
- `/pref_top` - показать топ предпочтений
- `/budget_limit значение` - установить лимит бюджета
- `/budget_add статья сумма дата` - добавить расход (дд.мм.гггг)
- `/budget_list` - показать расходы
- `/budget_tot` - показать итог бюджета
- `/task_add название дата` - добавить задачу (дд.мм.гггг)
- `/task_list all|today|3|done` - показать задачи
- `/task_done название` - отметить задачу как готовую
- `/today_tasks` - показать задачи на сегодня

## Данные

Все данные сохраняются в `data.json`.
